# 테스트 질문지 기준 자료

이 문서는 제공된 테스트 화면을 `assessment_version` `2026-08-20.1`의 질문 원문과 선택지에
연결한 사람이 읽기 위한 목록이다. 백엔드에서 읽을 수 있는 동일 기준 데이터는
[`assessment-content.v1.json`](./assessment-content.v1.json)에 있다. ID와 제출 값의 불변 계약은
[`assessment-identifiers.v1.json`](./assessment-identifiers.v1.json)이 계속 담당한다.

질문 원문, 선택지 원문, 입력 방식, 기존 제출 값에 더해 `temp.txt`의 최초 기획을 현재 문항의
의미에 맞춰 연결했다. 문항 역할, 판정 축, 선택지별 방향, 결과 재료 영역까지 매핑됐다. 축 신호는
동일 가중치 평균으로 집계한다. 카톡 개수는 300 미만이면 밀착 100점, 300 초과이면 거리조절
0점, 정확히 300이면 중립 50점이다. 최종 축 점수는 50점 이상일 때 100점 쪽 극으로 분류한다.
결과 페이지의 나머지 문구 조합 규칙은 아직 확정되지 않았다.

## MBTI 입력

문항 응답 이후 `E/I`, `S/N`, `T/F`, `J/P`를 각각 선택하고 조합한 네 글자 값을 API의
`mbti` 필드로 제출한다. 이 값은 20개 문항에서 채점해 산출하지 않는다.

## 결과 재료 매핑

### 1. 장난감 소개 (`overview`)

상단 키워드 3개는 MBTI 전체 유형의 대표 키워드 1개와 네 성향 축 중 50점에서 가장 멀리
떨어진 두 축의 극점 키워드로 구성한다. 편차가 같으면 애착유형, 표현방식, 자극추구,
에겐테토 순으로 선택한다.

### 2. 핵심 특징 (`features`)

항상 `동원력`, `관계 속의 나`, `마음 정리법`, `타고난 무기` 순서로 4개를 반환한다.
앞의 세 슬롯은 테스트 답변을 근거로 하고, 마지막 슬롯은 MBTI 16종 각각의 대표 특징을 사용한다.
동원력은 `step1.q11 + MBTI 보조`, 관계 속의 나는
`step1.q01 × step1.q02`, 마음 정리법은 분류된 `표현방식 × 에겐테토` 두 축, 타고난 무기는
제출된 MBTI 네 글자 전체만 사용한다. 타고난 무기는 MBTI를 유형군으로 묶지 않으므로 16개
유형이 각각 다른 결과를 갖는다. 마음 정리법에는 애착유형과 자극추구 축을 사용하지 않는다.
네 슬롯의 매칭 로직은 모두 구현됐으며, 타고난 무기의 16종 문구는 최종 콘텐츠 검수 대상으로
남아 있다. 세부 기획은
[`key-feature-product-plan.md`](./key-feature-product-plan.md)를 따른다.

### 3. 이렇게 다뤄주세요 (`can_do`)

#### `step1.q12` 기분이 안 좋을 때, 가장 반가운 친구의 연락은?

- `listen_to_me` → 무슨 일인지 천천히 들어줄게
- `take_me_out` → 일단 나와. 맛있는 거 먹자
- `give_me_space` → 혼자 정리되면 연락해. 기다릴게
- `solve_together` → 내가 같이 해결해볼까?
- `make_me_laugh` → 이거 보고 일단 웃어ㅋㅋ

`이렇게 다뤄주세요` 문구를 만들 때 이 답변을 핵심 재료로 사용하고, MBTI의 가운데 두 축을
문구 보조 재료로 사용한다.

네 문구는 다음 재료와 순서로 결정한다.

1. 힘들 때 원하는 도움: `step1.q12 × MBTI 가운데 두 축(NT/ST/NF/SF)`
2. 편안한 관계 거리: 애착유형 점수 `0~24`, `25~49`, `50~74`, `75~100` 네 구간
3. 갈등을 푸는 방식: `step2.q02 × step2.q03`
4. 호감 포인트: 제출한 `MBTI`에 대응하는 16종 고정 문구

`step1.q03`, `step1.q04`는 결과 생성에 사용되지 않아 `2026-08-18.1` 계약에서 삭제했다.

갈등을 푸는 방식은 서운함을 드러내는 방식인 `step2.q02`와 갈등 메시지를 보내기 전 숙고
속도인 `step2.q03`을 조합해 네 문구 중 하나를 사용한다.

편안한 관계 거리는 세 문항으로 계산한 애착유형 점수의 강도를 보존하기 위해 네 구간으로
나눈다. 내부 점수는 낮을수록 거리조절, 높을수록 밀착이며 각 구간은 양 끝값을 포함한다.

호감 포인트는 첫 만남에서 어떤 구체적인 접근에 호감과 설렘을 느끼는지 펫 게임의 반응
설명처럼 보여준다. 제출한 MBTI 네 글자 전체를 사용하며, 위로나 연락 빈도, 갈등 해결과 겹치는
내용은 넣지 않는다. `step2.q08`은 에겐테토 축과 궁합 재료로만 유지한다.

### 4. 이렇게 하면 고장나요 (`warnings`)

#### `step1.q06` 송송님을 화나게 하는 가장 빠른 방법

- `rush` → 재촉하기
- `interrupt` → 말 끊기
- `take_food` → 음식 뺏어먹기
- `arrive_late` → 약속 늦기
- `nag` → 잔소리
- `change_plan` → 내 계획 바꾸기

네 문구는 다음 재료와 순서로 결정한다.

1. 대화에서 상처받는 지점: MBTI `T/F × 표현방식`(직진 `50~100`, 탐색 `0~49`)
2. 사회적 에너지 경계: MBTI `E/I × 애착유형`(밀착 `50~100`, 거리조절 `0~49`)
3. 가장 빠른 분노 버튼: `step1.q06`
4. 유형별 발작 버튼: 제출한 `MBTI`에 대응하는 16종 고정 문구

Q06은 사용자가 직접 고른 구체적인 경계를 그대로 핵심 재료로 사용한다. 첫 슬롯은 MBTI `T/F`와
표현방식을 조합하고,
두 번째 슬롯은 MBTI `E/I`와 애착유형을 조합하고, 네 번째 슬롯에서는 MBTI 네 글자 전체를
사용한다. 유형별 발작 버튼은 상대가
사용자에게 한 구체적인 말이나 행동과 그때 나타나는 반응을 짧게 보여준다. `step1.q05`는 문항과
입력 계약에는 유지하지만 현재 결과 문구에는 사용하지 않으며, 향후 노출 위치는 제품 결정으로 남긴다.

### 5. 충전 방법 (`charging`)

충전 결과는 `step1.q07`, `step1.q08`, `step1.q11`, `step1.q12`를 역할별로 조합한다. 메인
설명은 Q07의 평소 회복 메커니즘과 Q11의 다시 기운이 올라오는 계기를 두 문장으로 연결해
61자 이하로 반환한다.
키워드 3개는 Q07의 평소 회복, Q08의 일정이 틀어졌을 때 선택하는 환기, Q12의 감정 회복을
각각 10자 이하로 보여준다. 세 키워드는 타인이 해줄 일을 지시하지 않고 사용자가 실제로 하는
충전 행동으로 표현한다. Q11과 Q12가 다른 결과 영역에서도 사용되더라도 같은 문구를 반복하지
않고 충전 맥락으로 다시 해석한다. MBTI는 사용하지 않으며 충전 점수도 API에서 제공하지 않는다.

#### `step1.q07` 기다리고 기다리던 휴일, 송송님의 첫 스케줄은 무엇인가요?

- `sleep_until_noon` → 낮 12시 기상
- `morning_run` → 아침 러닝
- `brunch_cafe` → 브런치 카페
- `stay_in_bed` → 이불 밖은 위험해
- `watch_streaming` → 밀린 OTT 시청
- `self_development` → 자기개발

Q07 선택지는 충전 결과에서 다음 메커니즘과 첫 문장으로 해석한다.

| 선택지 | 메커니즘 | 첫 문장 |
|---|---|---|
| `sleep_until_noon` | 수면 우선 | 잠이 충분히 채워져야 나머지가 돌아가는 사람이에요 |
| `morning_run` | 소모 | 에너지를 써야 오히려 채워지는 사람이에요 |
| `brunch_cafe` | 감각 만족 | 나한테 좋은 걸 제대로 챙겨줘야 채워지는 사람이에요 |
| `stay_in_bed` | 차단 | 혼자 아무것도 안 하는 시간이 있어야 채워지는 사람이에요 |
| `watch_streaming` | 몰입 | 뭔가에 푹 빠져서 딴생각이 안 날 때 채워지는 사람이에요 |
| `self_development` | 청산 | 마음의 짐을 덜어야 쉬어지는 사람이에요 |

#### `step1.q08` 금요일 저녁, 약속이 갑자기 취소됐을 때 송송님은

- `go_to_bed` → 개꿀! 당장 침대로 간다
- `contact_others` → 다른 친구한테 연락 돌린다
- `eat_alone` → 혼자라도 식당 가서 먹고 온다
- `go_for_drive` → 이 때다, 안 가 본 곳으로 드라이브!

### 6. 환상과 환장의 장난감 (`friend_compatibility`)

개인 결과 API는 이 영역을 `compatible_friends` 카드 2개로 제공한다. 직접 연결된 질문이나
성향 축은 없고, MBTI별 고정 궁합표의 첫 번째 후보에서 `환상의 장난감` 1개와
`환장의 장난감` 1개를 선택한다. 각 카드는 해당 MBTI 행에 확정된 설명을 사용한다.

## 성향 축 매핑

### 1. 표현방식 (탐색 vs 직진)

내부 점수 방향은 탐색 `0` ↔ 직진 `100`이다.

#### `step2.q01` “어? 저 사람 마음에 드는데?” 송송님의 첫 반응은?

- `inspect_profile` → 정독하며 성향 파악부터! 프로필부터 터는 SNS 염탐형 → **탐색**
- `approach_directly` → “오늘 시간 되세요?” 바로 직진하는 돌진형 → **직진**

#### `step2.q02` “방금 그 말, 좀 서운한데...” 대처 방식은?

- `hint_and_wait` → “내가 왜 이러는지 알아채봐” 말없이 티 내며 삭히는 고구마형 → **탐색**
- `resolve_immediately` → “방금 그 말 무슨 뜻이야?” 그자리에서 풀어야 하는 사이다형 → **직진**

#### `step2.q03` 친구랑 싸웠을 때 전송 버튼을 누르기 직전 송송님은?

- `rehearse_with_ai` → AI랑 몇번이고 상담한다 → **탐색**
- `send_immediately` → 고민 없이 바로 보낸다 → **직진**

최초 기획의 “메모장에 쓰고 보내지 않음/생각을 바로 말함”이 현재 문구로 변경된 것으로 보고
숙고와 즉시 표현이라는 의미를 기준으로 연결했다.

### 2. 애착유형 (밀착 vs 거리조절)

내부 점수 방향은 거리조절 `0` ↔ 밀착 `100`이다.

#### `step2.q04` 연애할 때, 우리 사이는 어느 정도가 편한가요?

- 슬라이더 왼쪽 → **밀착**
- 슬라이더 오른쪽 → **거리조절**
- 제출값은 `0·25·50·75·100` 중 하나이며 `0`은 밀착, `100`은 거리조절을 뜻한다.

애착유형 최종 점수는 Q04 50%, Q05 30%, Q06 20%의 가중 평균을 가장 가까운 정수로
반올림한다. Q04는 화면 방향을 뒤집어 밀착 `100`·거리조절 `0`으로 환산한 뒤 계산한다.

#### `step2.q05` 소소한 일상, 얼마나 공유하나요?

- `share_everything` → “오늘 뭐 먹었는지까지 다 말해야지!” → **밀착**
- `share_selectively` → “굳이 하나하나 보고할 필요는 없잖아?” → **거리조절**

#### `step2.q06` 지금 쌓여있는 카톡 개수는?

- 제출값은 `0~999` 정수다.
- 300개 미만 → **밀착** 100점
- 300개 초과 → **거리조절** 0점
- 정확히 300개 → **중립** 50점

### 3. 에겐테토 (에겐 vs 테토)

내부 점수 방향은 테토 `0` ↔ 에겐 `100`이다.

#### `step2.q07` 드디어 첫 자취 시작! 어떻게 방을 꾸미실 건가요?

- `decorate_for_mood` → 조명 하나, 포스터 하나까지 감성은 필수 → **에겐**
- `essentials_only` → 매트리스랑 가전만 있으면 생활 쌉가능 → **테토**

#### `step2.q08` 누군가를 챙기거나 애정을 표현할 때 어떻게 하나요?

- `express_with_words` → 다정한 말투, 폭풍 리액션, 눈빛과 표현으로 채운다 → **에겐**
- `express_with_actions` → 말은 별로 없지만 슬쩍 챙겨주거나 행동으로 보여준다 → **테토**

#### `step2.q09` 어젯밤 내가 단톡방에 보낸 드립에 그 누구도 관심 주지 않았을 때,

- `ruminate` → “괜히 보냈나...” 계속해서 곱씹어본다 → **에겐**
- `forget_quickly` → 보낸 기억도 없다 → **테토**

### 4. 자극추구 (루틴 vs 탐험)

내부 점수 방향은 탐험 `0` ↔ 루틴 `100`이다.

#### `step2.q10` 자주 가던 단골카페에 새로운 메뉴가 생겼다.

- `order_familiar_menu` → 괜히 먹었다가 맛 없으면 어떡해? 원래 계속 먹던 거 또 시켜 먹는다 → **루틴**
- `try_new_menu` → 안 먹어본 신메뉴가 나왔다고? 일단 도전해보자! → **탐험**

#### `step2.q11` 배달 앱 최근 주문 내역에 들어가보세요.

- `order_familiar_stores` → 늘 시키던 맛집 몇 곳만 돌아가며 주문한다. → **루틴**
- `try_new_store` → 리뷰가 없어도 새로운 가게를 도전한다. → **탐험**

최초 기획에서는 Q12였지만 현재 화면의 질문 의미와 진행 순서를 기준으로 `step2.q11`에 연결했다.

#### `step2.q12` 송송님 앞에 나타난 금지 버튼, 누르실건가요?

- `press` → PUSH 버튼 누르기 → **탐험**
- `skip` → 건너뛰기 → **루틴**

최초 기획에서는 Q11이었지만 현재 화면의 질문 의미와 진행 순서를 기준으로 `step2.q12`에 연결했다.
