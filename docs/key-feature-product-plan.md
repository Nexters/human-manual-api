# 핵심 특징 기획안

## 1. 목적

결과 페이지의 `KEY FEATURES`는 사용자를 네 가지 관점에서 빠르게 이해하게 만드는 영역이다.
테스트 선택지를 그대로 되풀이하거나 MBTI의 일반적인 설명을 나열하지 않고, 사용자가 읽었을 때
“내가 실제로 이렇다”라고 알아볼 수 있는 특징을 보여준다.

핵심 특징은 항상 네 개이며, 아래 네 슬롯을 순서대로 하나씩 반환한다.

## 2. 확정 슬롯

### 슬롯 1. 동원력

**나를 움직이게 만드는 것**

관심만 갖고 끝나는 대상과 실제 행동까지 하게 만드는 대상을 구분해, 무엇이 이 사람의 행동
스위치를 켜는지 설명한다.

- 다루는 것: 행동을 시작하게 만드는 자극, 관심, 목적 또는 상황
- 다루지 않는 것: 지쳤을 때 회복하는 활동이나 휴식법
- 답해야 하는 질문: “이 사람은 무엇을 만나면 움직이기 시작하는가?”

#### 확정 문항

기존 질문만으로는 동원력을 직접 판별하기 어려워 다음 단일 선택 문항 `step1.q11`을 사용한다.

> 주말 내내 집에만 있으려고 했는데, 결국 밖에 나와버리고 말았다. 그 이유는?

| 값 | 선택지 | 판별하는 동원 원인 |
| --- | --- | --- |
| `curiosity` | SNS에서 처음 보는, 흥미로워 보이는 팝업을 봤다. | 궁금증과 확인 욕구 |
| `needed_by_someone` | 친구가 “이건 진짜 너밖에 못 도와줘”라며 불러냈다. | 필요받는 감각과 도움 |
| `clear_goal` | 러닝 앱을 켜보니 이번 주 목표까지 딱 한 번만 남아 있었다. | 스스로 정한 목표와 성취 |
| `responsibility` | 친구의 이사를 도와주기로 한 시간이 다가오고 있었다. | 약속과 자기 몫에 대한 책임 |
| `last_chance` | 계속 미뤄둔 전시가 오늘 문을 닫는다는 걸 알았다. | 기회를 놓치고 싶지 않은 마음 |
| `fun` | 친구들이 벌써 모여 웃고 난리 난 영상을 단톡방에 올리며 당장 나오라고 했다. | 즐거움에 합류하고 싶은 마음 |

이 문항의 선택값이 동원 원인을 결정하고, MBTI는 같은 동기가 어떤 방식의 행동으로 이어지는지
구체화하는 보조 재료로 사용한다. MBTI만으로 동원 원인을 바꾸거나 입력에 없는 동기를 추가하지
않는다.

이 문항의 핵심 특징 슬롯은 “가만히 있던 사람을 무엇이 행동하게 만드는가”를 설명한다. 충전
방법에서도 같은 답을 재사용하지만, 회복 뒤 다시 시동이 걸리는 조건만 짧게 보여주며 동원력
문구를 반복하지 않는다.

#### 확정 출력 규칙

선택값은 동원 원인과 제목을 결정한다. MBTI는 별도의 특징 문장을 붙이지 않고 `NT`, `ST`,
`NF`, `SF`의 사고 결로만 보조한다. 동원 원인마다 네 사고 결에 맞는 완성 문장을 따로 두어,
관련 없는 MBTI 문구가 뒤에 붙는 현상을 막는다. 허용된 `6 × 16` 입력은 아래 24개 고정 문장
중 하나로 결정된다.

| 값 | 제목 |
| --- | --- |
| `curiosity` | 궁금한 건 못 참아요 |
| `needed_by_someone` | 의리가 강해요 |
| `clear_goal` | 끝은 봐야 해요 |
| `responsibility` | 약속했으면 지켜요 |
| `last_chance` | 기회는 꼭 잡아요 |
| `fun` | 재밌는 건 해야 해요 |

MBTI 그룹은 `NT = INTJ·ENTJ·INTP·ENTP`, `ST = ISTJ·ESTJ·ISTP·ESTP`,
`NF = INFJ·ENFJ·INFP·ENFP`, `SF = ISFJ·ESFJ·ISFP·ESFP`로 나눈다. 실제 24개 문장은
`src/pakit/services/result_content.py`의 `MOTIVATION_DESCRIPTION`을 단일 원본으로 사용한다.

### 슬롯 2. 관계 속의 나

**사람들 사이에서 자연스럽게 맡는 역할**

친구, 연인 또는 모임 안에서 이 사람이 자연스럽게 보태는 기능을 설명한다. 직책처럼 고정된
역할보다 사람들이 실제로 이 사람을 찾게 되는 이유와 주변에 만드는 변화를 보여준다.

- 다루는 것: 관계에서의 기여, 자연스럽게 맡는 역할, 주변에 만드는 변화
- 다루지 않는 것: 상대가 이 사람에게 해줘야 하는 행동
- 답해야 하는 질문: “사람들 사이에서 이 사람은 어떤 역할을 하게 되는가?”

#### 확정 재료

- `step1.q01`: 친구들이 이 사람부터 찾는 순간 → 관계에서 필요해지는 상황
- `step1.q02`: 친구들 사이에서 자연스럽게 맡는 역할 → 그 상황에 기여하는 방식

두 답변을 `step1.q01 × step1.q02`로 조합해 특징 하나를 만든다. 선택지 두 개를 따로
풀이하거나 특징 두 개로 늘리지 않는다. 예를 들어 `답이 안 나는 고민 × 실제 계획으로 만들기`는
복잡한 고민을 실행할 순서로 정리해주는 역할로 해석한다.

두 문항만으로 관계 역할의 근거가 충분하므로 MBTI는 사용하지 않는다.

#### 확정 출력 규칙

`step1.q01`의 4개 값과 `step1.q02`의 6개 값을 조합해 총 24개 고정 결과를 만든다. 각 조합은
관계 역할 하나만 반환하며, 질문의 선택지 문장을 그대로 제목으로 옮기지 않는다. 예를 들어
`결정을 못 할 때 × 방향부터 정하기`는 여러 사람의 조건을 읽고 선택을 좁혀주는
`결정 대장`으로 해석한다.

24개 제목과 설명은 `src/pakit/services/result_content.py`의 `RELATIONSHIP_ROLE_COPY`를 단일
원본으로 사용한다. 관계 역할 제목은 공백 포함 7자 이하이고 설명은 한 문장으로 작성한다.
제목은 기능명이 아니라 친구들이 붙여줄 법한 별명처럼 쓰고, 설명은 관계 속에서 반복해서 보이는
모습을 `~하는 사람이에요` 형태로 보여준다.

### 슬롯 3. 마음 정리법

**생각과 감정을 내 안에서 정리하는 방식**

서운함, 혼란, 민망함이나 갈등이 생긴 뒤 이 사람이 그것을 인식하고 소화하고 정리하는 과정을
설명한다.

- 다루는 것: 생각과 감정을 이해하는 방식, 표현 전 숙고, 감정의 잔상과 정리 과정
- 다루지 않는 것: 이 사람을 화나게 만드는 외부 조건이나 금지 행동
- 답해야 하는 질문: “마음에 무언가 생겼을 때 이 사람은 그것을 어떻게 정리하는가?”

#### 확정 재료

- `expression` 분류: 탐색형 또는 직진형
- `egen` 분류: 테토형 또는 에겐형

분류가 끝난 두 축을 `표현방식 × 에겐테토`로 조합해 총 4개 결과를 만든다.

| 조합 | 마음 정리법에서 해석하는 내용 |
| --- | --- |
| 탐색 × 에겐 | 마음을 충분히 들여다본 뒤 말과 감정으로 차근차근 풀어낸다. |
| 직진 × 에겐 | 생긴 마음을 바로 확인하고 서로의 감정을 말로 맞춰야 정리된다. |
| 탐색 × 테토 | 바로 말하기보다 상황을 정리한 뒤 필요한 행동으로 마음을 정돈한다. |
| 직진 × 테토 | 걸리는 것을 바로 확인하고 해결한 뒤 다음 행동으로 넘어간다. |

`expression`은 마음을 언제 밖으로 표현하는지를, `egen`은 말과 감정 또는 행동 중 어느 쪽으로
풀어내는지를 결정한다. 애착유형은 관계에서 원하는 거리를 뜻하므로 사용하지 않고, 자극추구는
새로움 선호를 뜻하므로 사용하지 않는다. MBTI도 사용하지 않는다.

이 슬롯은 감정을 일으키는 외부 조건을 설명하지 않으므로 `이렇게 하면 고장나요`와 구분한다.
또한 축 이름을 결과 문구에 노출하거나 언박싱 키트의 포장·도구 설명을 반복하지 않는다.

#### 확정 출력 규칙

| 조합 | 제목 | 설명 |
| --- | --- | --- |
| 탐색 × 에겐 | 혼자 곱씹어요 | 마음이 복잡하면 바로 꺼내기보다 충분히 들여다보고, 준비가 되면 차근차근 말해요. |
| 직진 × 에겐 | 서운하면 직구 | 서운한 건 쌓아두지 않고 바로 꺼내, 서로의 마음을 확인해야 풀려요. |
| 탐색 × 테토 | 생각정리 먼저 | 마음이 복잡할수록 먼저 상황을 정리하고, 말보다 필요한 행동으로 풀어내요. |
| 직진 × 테토 | 바로 해결해요 | 걸리는 건 바로 확인하고, 해결할 일을 끝낸 뒤 다음 행동으로 넘어가요. |

네 제목과 설명은 `src/pakit/services/result_content.py`의 `EMOTIONAL_PROCESSING_COPY`를 단일
원본으로 사용한다. 이 슬롯은 별도 헤더 없이 제목만 노출돼도 행동 특성을 이해할 수 있도록
작성하며, 제목은 공백 포함 7자 이하로 제한한다. 점수가 정확히 50이면 각각
직진과 에겐으로 분류한다.

### 슬롯 4. 타고난 무기

**MBTI 16종 각각의 대표 특징**

MBTI 캐릭터가 가진 대표 특징 하나를 설명한다. MBTI 코드를 직접 보여주거나 고정관념을
나열하지 않고, 일상에서 실제로 드러나는 사고와 행동의 강점으로 표현한다.

- 다루는 것: 유형의 네 글자 전체에서 드러나는 대표적인 사고·행동 강점
- 다루지 않는 것: 외향·내향을 충전 방식으로 풀이하거나, 판단·인식을 계획형·즉흥형으로만
  설명하는 전형적인 유형 해설
- 답해야 하는 질문: “이 사람이 자연스럽게 잘 쓰는 사고의 무기는 무엇인가?”

#### 확정 재료

- 제출된 `mbti`: 16개 유형별 대표 특징 하나

다른 테스트 문항이나 성향 축을 결합하지 않고 제출된 MBTI 네 글자 전체만 사용한다. `NT`,
`ST`, `NF`, `SF` 또는 `J/P`처럼 일부 글자만 떼어 유형군으로 묶지 않으며, 16개 유형이 각각
다른 제목과 설명을 갖는다. 유형별 특징은 PRD의 MBTI 한 줄 요약을 기준으로 하나씩 확정한다.
E/I를 충전 방식으로만 해석하거나 J/P를 계획형과 즉흥형으로만 설명하는 전형적인 문구는 피한다.

#### 검수용 출력 규칙

| MBTI | 제목 | 설명 |
| --- | --- | --- |
| INTJ | 큰그림을 봐요 | 흩어진 조각을 연결해 전체가 맞아떨어지는 구조를 봐요. |
| ISTJ | 끝까지 해내요 | 맡은 일은 빠뜨리는 것 없이 마지막 칸까지 채워요. |
| ENTJ | 목표를 이뤄요 | 멀리 있는 목표도 사람과 자원을 모아 앞으로 끌고 가요. |
| ESTJ | 순서대로 해요 | 엉킨 상황에서도 역할과 순서를 빠르게 다시 세워요. |
| INFJ | 마음을 읽어요 | 겉으로 한 말보다 그 안에 숨은 의도와 마음을 먼저 읽어요. |
| ISFJ | 내편은 지켜요 | 한번 자기 사람으로 받아들이면 필요한 순간을 지켜줘요. |
| ENFJ | 용기를 줘요 | 상대도 몰랐던 장점을 발견해 스스로 보게 해줘요. |
| ESFJ | 모두를 챙겨요 | 작은 안부와 배려로 사람 사이가 부드럽게 돌아가게 해요. |
| INFP | 소신을 지켜요 | 남의 기준보다 자신이 진짜 중요하게 여기는 것을 지켜요. |
| ISFP | 감각을 믿어요 | 말로 설명하기 전에도 자신에게 맞는 결을 알아봐요. |
| ENFP | 가능성을 봐요 | 사람과 상황에서 아직 펼쳐지지 않은 재미를 먼저 발견해요. |
| ESFP | 지금을 즐겨요 | 지금 이 순간의 즐거움을 찾아 주변 사람과 함께 나눠요. |
| INTP | 원리를 따져요 | 당연해 보이는 것도 작동 원리를 알 때까지 파고들어요. |
| ISTP | 직접 해결해요 | 설명만 늘이기보다 직접 만져 가장 빠른 해결책을 찾아요. |
| ENTP | 다르게 봐요 | 모두가 당연하다고 넘긴 곳에서 다른 가능성을 발견해요. |
| ESTP | 기회를 잡아요 | 눈앞의 변화를 빠르게 읽고 잡을 수 있을 때 움직여요. |

16개 결과는 `src/pakit/services/result_content.py`의 `MBTI_STRENGTH_COPY`를 단일 원본으로
사용하며, 제목은 공백 포함 7자 이하로 제한한다.

## 3. 결과 페이지 내 역할 구분

| 결과 영역 | 담당하는 내용 | 핵심 특징과의 경계 |
| --- | --- | --- |
| 언박싱 키트 | 표현, 관계 거리, 새로움, 애정 표현의 기본 작동 원리 | 네 성향 축을 핵심 특징에서 다시 해설하지 않는다. |
| 핵심 특징 | 동원력, 관계 역할, 마음 정리, MBTI 사고 강점 | 사용자의 반복적인 내부·관계 패턴을 설명한다. |
| 이렇게 다뤄주세요 | 상대가 이 사람에게 해주면 좋은 행동 | 관계 속의 나는 반대로 이 사람이 주변에 하는 일을 다룬다. |
| 이렇게 하면 고장나요 | 피해야 할 행동과 불편함이 생기는 조건 | 마음 정리법은 이미 생긴 마음을 내부에서 처리하는 과정을 다룬다. |
| 충전 방법 | 평소 회복·일정 변경 시 환기·감정 회복과 다시 기운이 나는 계기 | 동원력 문구를 반복하지 않고 실제 충전 행동으로 연결한다. |

## 4. 데이터 사용 원칙

- 슬롯 1은 `step1.q11`의 답변을 중심으로 하고 MBTI를 보조 재료로 사용한다.
- 슬롯 2는 `step1.q01 × step1.q02` 답변만 사용하며 MBTI는 사용하지 않는다.
- 슬롯 3은 분류된 `expression × egen` 두 축만 사용하며 MBTI는 사용하지 않는다.
- 슬롯 4는 제출된 MBTI 네 글자 전체만 사용해 16개 유형별 대표 특징 하나를 결정한다.
- 여러 결과 영역에서 같은 답변을 사용할 수는 있지만, 같은 해석과 문장을 반복해서는 안 된다.
- 하나의 선택지만으로 삶 전체의 성향을 단정하지 않는다.
- 상대에 관한 선택지를 사용자의 특징으로 뒤집지 않는다.
- 입력에 없는 행동, 시간, 빈도, 감정의 강도와 지속 시간을 만들지 않는다.
- 결과는 검수된 고정 규칙과 카피로 결정하며 LLM을 사용하지 않는다.

## 5. 카피 원칙

- 제목만 읽어도 어떤 특징인지 이해할 수 있어야 한다.
- 설명은 선택지 해설이 아니라 실제 생활에서 관찰할 수 있는 모습으로 쓴다.
- `판단력이 좋다`, `공감 능력이 높다` 같은 평가표 표현보다 구체적인 행동을 보여준다.
- MBTI 코드, 문항 ID, 내부 성향 축 이름을 결과 문장에 직접 노출하지 않는다.
- 네 슬롯은 서로 다른 내용을 말해야 하며, 좋은 말만 네 번 반복하지 않는다.
- 공유받은 친구나 연인이 대화를 이어갈 만한 생활 장면을 포함한다.

## 6. API 표시 순서

`features` 배열은 다음 순서를 유지한다.

1. 동원력
2. 관계 속의 나
3. 마음 정리법
4. 타고난 무기

각 항목은 현재 계약대로 `title`과 `description`을 제공한다. 슬롯을 프론트엔드가 별도 라벨로
노출할지는 UI 결정 전까지 확정하지 않는다.

## 7. 아직 확정하지 않은 것

- MBTI 16종 문구의 최종 콘텐츠 검수
- API에 슬롯 ID를 추가할지 여부

위 항목이 결정되기 전에는 현재 구현을 새 기획의 최종 규칙으로 간주하지 않는다.
