# 연인 관계 설명서 유저 프롬프트 템플릿

아래 두 사람의 성향 프로필을 바탕으로 연인 관계 설명서를 작성하세요.

이 설명서는 두 사람이 서로를 덜 오해하고, 반복되는 갈등 패턴을 알아차리며, 더 나은 관계
방식을 함께 만들어갈 수 있도록 돕는 글이어야 합니다.

## {{participant_a_name}} 프로필

- 성별: {{participant_a_gender}}
- MBTI: {{participant_a_mbti}}
{{participant_a_profile}}

## {{participant_b_name}} 프로필

- 성별: {{participant_b_gender}}
- MBTI: {{participant_b_mbti}}
{{participant_b_profile}}

## 작성 조건

총 10개의 항목으로 구성하세요.

각 항목은 다음 형식을 따르세요.

```markdown
## 1. 항목 제목

설명 문단
```

항목 제목은 직관적으로 작성하세요. “우리에게도 이런 순간이 있었을 수 있겠다”고 느끼고
공감할 수 있는 글을 써주세요.

각 항목의 설명은 약 1,000byte 내외로 작성하세요. 구체적인 관계 장면, 말의 뉘앙스,
서로 다르게 받아들일 수 있는 지점, 실천 가능한 제안을 자연스럽게 포함하세요.

### 고정 항목

첫 번째 항목은 반드시 다음 제목으로 작성하세요.

```markdown
## 1. 이 관계의 핵심 구조
```

2번부터 6번까지는 두 사람의 차이에서 발견한 핵심 관계 주제 가운데 서로 겹치지 않는 다섯
가지를 선택해 제목을 직접 만드세요. 프로필 항목을 순서대로 요약하지 말고, 두 사람의 정보가
만났을 때 생기는 관계의 장면과 상호작용을 중심으로 구성하세요.

### 닉네임과 주체를 명확히 쓰는 규칙

- 각 항목에서 핵심 차이를 처음 설명하는 문장에는 반드시
  `{{participant_a_name}}님`과 `{{participant_b_name}}님`을 모두 쓰세요.
- 2번부터 6번까지의 제목에서도 “기다리는 사람과 묻는 사람”처럼 역할만 나열하지 마세요.
  두 사람의 반응 차이를 제목에 담는다면 “{{participant_b_name}}님이 기다릴 때
  {{participant_a_name}}님이 먼저 묻는 이유”처럼 닉네임으로 주체를 밝히세요.
- 행동, 감정, 바라는 것, 두려워하는 것, 오해하는 내용을 설명할 때 그것이 누구의 것인지
  닉네임에 직접 연결하세요.
- 두 사람의 차이가 입력에서 확인된다면
  “{{participant_b_name}}님은 {{participant_a_name}}님보다 …”처럼 비교 대상을 분명히
  쓰세요. 입력이 비교 방향을 뒷받침하지 않으면 우열이나 정도 차이를 만들지 말고 두 사람의
  반응을 각각 닉네임으로 설명하세요.
- 관계의 반복 과정을 쓸 때는
  “{{participant_a_name}}님이 … → {{participant_b_name}}님은 …로 받아들임 →
  {{participant_b_name}}님의 반응을 본 {{participant_a_name}}님은 …”처럼 행동과 반응의
  주체를 끝까지 표시하세요.
- “한 사람”, “다른 사람”, “한쪽”, “다른 쪽”, “상대”, “질문한 쪽”, “질문받은 쪽”으로
  두 사람을 익명화하지 마세요.
- 실제 대화 예시를 제안할 때도 누가 할 말인지 닉네임으로 표시하세요.
- 위 구조를 지키되 모든 문단을 같은 문장 형식으로 반복하지는 마세요.

마지막 네 개 항목은 반드시 다음 순서로 작성하세요.

```markdown
## 7. 이 관계가 가진 힘

## 8. 서로에게 해주면 좋은 것

## 9. 둘만의 관계 규칙

## 10. 이 관계의 성장 방향
```

8번은 하나의 장 안에서 양방향으로 구성하세요.

- {{participant_a_name}} → {{participant_b_name}}
- {{participant_b_name}} → {{participant_a_name}}

9번에서는 두 사람에게 실제로 도움이 될 관계 규칙을 3개에서 5개까지 제안하세요. 각 규칙은
다음 형식을 사용하세요.

```markdown
규칙 1. [규칙 제목] 설명

규칙 2. [규칙 제목] 설명

규칙 3. [규칙 제목] 설명
```

필요하면 규칙 4와 규칙 5까지 작성할 수 있습니다.

10번은 이 관계가 더 좋아지기 위해 기억하면 좋은 핵심을 한 줄로 작성하세요.

## 출력 시 주의사항

- 궁합을 판정하지 말고 관계의 작동 방식을 설명하세요.
- 두 사람의 차이가 어떤 오해를 만들 수 있는지 보여주세요.
- 각자가 그렇게 반응하는 내면의 이유를 설명하세요.
- 반복될 수 있는 상호작용 패턴을 찾아주세요.
- 함께 바꿔볼 수 있는 구체적인 방법을 제안하세요.
- 입력에 없는 사실은 단정하지 마세요.
- 두 사람의 개인 사용 설명서를 별도 항목으로 작성하지 마세요.
- 같은 차이나 조언을 제목만 바꿔 반복하지 마세요.
- 독자가 모든 문장에서 행동과 감정의 주체를 바로 알 수 있게 닉네임을 사용하세요.
